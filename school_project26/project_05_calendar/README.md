## 🌟 프로젝트 소개

직업계 고등학교 도제교육(일학습병행제)은 교내 교육(**off-JT**), 기업 현장 훈련(**OJT**), 특별수업, 국가공휴일 및 역량평가 마일스톤이 복합적으로 얽혀 있어 일정 관리가 까다롭습니다.

본 시스템은 **Google Spreadsheet**를 간편한 DB로 사용하면서, 학생·학부모에게는 미려한 **반응형 캘린더와 이수시간 통계**를, 관리자에게는 **보안 인증 기반의 실시간 일정/공지/D-Day 편집 기능**을 제공합니다.

---

## ✨ 주요 기능

### 1. 📆 월간 / 1주간 / 2주간 인터랙티브 캘린더
- **월간 뷰(Month View)**: 한 달 전체 일정과 이전/다음 달 연결 날짜 한눈에 확인
- **1주간 뷰(1 Week View)**: 7일간의 집중된 상세 일정 확인
- **2주간 뷰(2 Weeks View)**: 14일간(2주)의 연속된 교육/훈련 일정 흐름 파악
- **스마트 카테고리 색상**:
  - 🔵 **교내 교육 (off-JT)**: 파란색
  - 🔴 **현장 훈련 (OJT)**: 빨간색
  - 🟢 **특별수업 (방과후)**: 녹색
  - 🟣 **특별수업 (기타 특강/캠프 등)**: 보라색
  - 🌸 **휴업일 / 공휴일**: 연분홍/적색
  - ⚪ **학사일정 / 일반**: 회색
- **다중 선택 필터링 (Multi-Select)**: `학사일정`, `off-JT`, `OJT`, `특별수업` 등 여러 카테고리를 2개 이상 동시에 겹쳐서 선택하여 원하는 일정만 맞춤형으로 조회 가능 (전체 일정 보기 클릭 시 전체 복귀)

### 2. 📊 스마트 대시보드 및 통계 자동 집계
- 현재 보고 있는 달력 화면을 기준으로 **off-JT 일수 및 총 이수시간** 자동 산출 (기본 7h 또는 `(N)` 시간 파싱)
- **OJT 일수 및 총 이수시간** 자동 산출 (기본 8h 또는 `(N)` 시간 파싱)
- **가장 가까운 마일스톤 D-Day** (예: `D-12`, `D-Day`) 및 명칭 실시간 표시

### 3. 📢 실시간 공지사항 배너
- 상단 배너를 통해 학교/도제부 공지사항을 실시간으로 안내

### 4. 📸 일정표 이미지 캡처 & 다운로드
- **2주간 탭 바로 옆** 및 **상단 헤더**에 `📸 일정표 저장` 버튼 제공
- **월간 / 1주간 / 2주간** 현재 보고 있는 **순수 달력 영역만을 2배율 고해상도 PNG 파일(`성일정보고_달력_{월간/1주간/2주간}_{기간}.png`)**로 즉시 저장 (학급 단톡방이나 가정통신문 첨부 시 유용)
- 캡처 시 저장 버튼 및 관리자 패널은 자동으로 숨김 처리되어 깔끔한 달력 이미지 생성

### 5. 🔐 관리자 전용 편집 모드
- **비밀번호 기반 보안 인증**: 서버(`Script Properties`)에 저장된 비밀번호로 30분 유효 세션 토큰 발급
- **공지사항 즉각 수정**: 상단 공지 실시간 변경
- **디데이(D-Day) 마일스톤 관리**: 평가 일정, 자격증 시험 등 추가/삭제
- **신규 일정 등록**: 날짜, 분류, 이수시간(기본값/직접입력), 일정명 입력으로 즉시 스프레드시트 반영
- **직관적인 일정 삭제**: 각 일정 배지의 `×` 버튼으로 개별 일정 삭제

## 🛠 기술 스택 및 아키텍처

```
[ Web Browser (Client) ]
       │
       │ HTTP GET/POST (JSON)
       ▼
[ Google Apps Script (Web App) ] ── (LockService & CacheService)
       │
       ▼
[ Google Spreadsheet (Database) ]
  ├── [YYYY.M] 월별 일정 시트
  ├── [설정] 공지사항 시트
  └── [디데이] 마일스톤 시트
```

- **Frontend**: Single-File HTML (`HTML5`, `CSS3 Glassmorphism`, `Vanilla JavaScript ES6+`)
- **Backend**: Google Apps Script (`Code.gs`)
- **Database**: Google Spreadsheet
- **Libraries**: `html2canvas` (화면 캡처, CDN 동적 로드)

## 📊 데이터베이스(스프레드시트) 구조

스프레드시트는 아래 3가지 유형의 시트로 구성됩니다.

### 1. 월별 시트 (시트명: `YYYY.M` 또는 `YYYY.MM`, 예: `2026.3`)
| A열 (일) | B열 (요일) | C열 (학사일정) | D열 (off-JT) | E열 (OJT) | ... |
| :---: | :---: | :--- | :--- | :--- | :--- |
| 1 | 일 | 삼일절 | | | |
| 2 | 월 | 개학식 및 입학식 | | | |
| 3 | 화 | | 네트워크 기초 (7) | | |
| 4 | 수 | | | 현장 실무 훈련 (8) | |

> **💡 셀 저장 메커니즘**:
> - 한 날짜/분류에 여러 일정이 있을 경우 개행(`\n`)으로 구분 저장됩니다.
> - 셀 Note(메모)에 JSON 형태로 일정 고유 식별자(UUID)가 함께 보관되어 안전한 수정/삭제가 가능합니다.

### 2. `설정` 시트
- **A1**: `Notice`
- **B1**: 공지사항 문구 (예: `2026학년도 1학기 도제과정 안내`)

### 3. `디데이` 시트
| A열 (목표 날짜) | B열 (디데이 명칭) | C열 (__id, 숨김열) |
| :--- | :--- | :--- |
| `2026-04-15` | `1차 도제역량평가` | `4f9b8c2e-...` (UUID) |
| `2026-06-20` | `과정평가형 자격 외부평가` | `7a8b9c0d-...` (UUID) |

## 🚀 배포 및 설치 가이드

### Step 1. 구글 스프레드시트 준비
1. 새 Google Spreadsheet를 생성합니다.
2. `확장 프로그램` > `Apps Script`를 클릭합니다.

### Step 2. Apps Script 코드 반영 및 비밀번호 설정
1. 생성된 Apps Script 편집기에 `code.gs`의 전체 내용을 복사하여 붙여넣고 저장합니다.
2. 좌측 메뉴의 **프로젝트 설정(톱니바퀴 아이콘)** > **스크립트 속성**으로 이동합니다.
3. **스크립트 속성 추가**를 클릭하고 다음 값을 등록합니다:
   - **속성**: `ADMIN_PASSWORD`
   - **값**: `원하는 관리자 비밀번호 입력`

### Step 3. 웹 앱 배포
1. 우측 상단 **배포** > **새 배포**를 클릭합니다.
2. 유형 선택: **웹 앱(Web App)**
   - **설명**: `v1.5`
   - **다음 사용자로 실행**: `나(내 계정)`
   - **액세스 권한이 있는 사용자**: `모든 사용자(Anyone)`
3. **배포** 버튼을 누르고 권한을 승인한 뒤 발급된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.

### Step 4. 프론트엔드 연동
1. `school_project_05_gas.json` 파일을 열어 `gas_url`에 복사한 Web App URL을 입력합니다:
   ```json
   {
     "gas_url": "https://script.google.com/macros/s/AKfycb.../exec"
   }
   ```
2. 웹 서버(GitHub Pages, Live Server 등)에 배포하거나 로컬 웹 서버로 `school_project_05_calendar.v1.0.html`을 실행합니다.

## 🔍 코드 상세 분석

### 1. 백엔드 (`code.gs`) 핵심 로직
- **`doGet()`**:
  - `설정` 시트의 공지사항 읽기
  - `디데이` 시트의 마일스톤 목록 파싱 (`readMilestones_`)
  - 정규식 `/^(\d{4})\.(0?[1-9]|1[0-2])$/`으로 모든 월별 탭을 스캔하여 일자별/분류별 이벤트 목록 추출 (`readMonthlyEvents_`)
  - 통합 JSON 응답 반환
- **`doPost(e)`**:
  - `action === 'verify'`: 비밀번호 대조 후 UUID 기반 30분 유효 세션 토큰 발행 (`CacheService` 활용)
  - `action === 'logout'`: 세션 캐시 제거
  - `LockService`: 데이터 갱신 작업 시 동시성 충돌 방지를 위한 10초 스크립트 락 적용
  - `update_notice`, `add_event`, `delete_event`, `add_dday`, `delete_dday` 분기 처리
- **안전한 데이터 관리**:
  - 셀 메모(Note)에 JSON 형태(`{ version: 1, items: [{ id, title }] }`)로 UUID를 보관하여 일정 삭제 시 정확한 대상을 매칭

### 2. 프론트엔드 (`school_project_05_calendar.v1.0.html`) 핵심 로직
- **데이터 인덱싱 (`buildEventIndex`)**:
  - 서버에서 받은 월별 일정 데이터를 `Map<day, events[]>` 구조로 가공하여 O(1)에 가까운 셀 렌더링 성능 확보
- **월간/주간 뷰 렌더러 (`renderCalendarMonth`, `renderCalendarWeek`)**:
  - 월간: 1일의 시작 요일 및 해당 월 총 일수를 계산하여 빈 칸과 날짜 셀을 그리드 배치
  - 주간: 선택된 주의 일~토 7일간의 날짜를 계산하여 상세 뷰 생성
- **이수 시간 및 D-Day 계산 (`processEventsToCell`, `calculateDDay`)**:
  - 일정 문자열에서 `(N)` 패턴을 정규식으로 추출하여 시간 합산 (미지정 시 off-JT 7시간, OJT 8시간 기본값 적용)
  - `Set`을 활용하여 하루에 여러 건이 있어도 중복 없이 총 훈련 일수를 정확하게 산출
- **화면 캡처 (`saveAsImage`)**:
  - `loadCaptureLibrary`로 `html2canvas`를 필요 시점에 비동기 로드
  - 관리자 패널 숨김 처리 후 2배율 캡처 수행 및 PNG 자동 다운로드
