## 1. 프로젝트 개요 (Overview)

**Morning Note**는 교실 현장에서 매일 반복되는 아침 전달사항 공지를 간소화하고, 학급 구성원 간의 정서적 유대감을 높이기 위해 기획되었습니다. 

별도의 유료 데이터베이스나 서버 인프라를 구축할 필요 없이, **Google Apps Script(GAS)**와 **Google Sheets**를 백엔드/데이터베이스로 활용하며, 브라우저 표준 기술(Vanilla HTML5, CSS3, ES6+ JS, Canvas 2D API)만으로 경량화된 반응형 웹 애플리케이션을 구현했습니다.

### 핵심 특징
- **Zero-Dependency 클라이언트**: 무거운 외부 번들러나 UI 라이브러리 없이 네이티브 웹 기술로 최고 수준의 성능과 로딩 속도 보장
- **서버리스 백엔드 (Serverless Architecture)**: Google Sheets 기반 무료 무제한 데이터 저장 및 Google Apps Script RESTful 통신
- **원클릭 고화질 카드 이미지 생성**: 외부 렌더링 라이브러리(html2canvas 등) 없이 순수 Canvas 2D 엔진으로 850px 태블릿 최적화 카드 이미지 렌더링 및 모바일 Web Share API 연동
- **엔터프라이즈급 보안 설계**: PBKDF 계열의 Salted SHA-256 해싱, 세션 슬라이딩 만료(30분), 5회 실패 시 5분 계정 잠금, 시트 수식 인젝션 방어

## 2. 제품 요구사항 정의서 (PRD)

### 2.1 프로젝트 비전 및 목적
- **비전**: 교사의 학급 소통 업무를 디지털화하고, 학생들에게 친근하고 기억에 남는 시각적 공지 경험을 제공한다.
- **목적**:
  - 매일 아침 조회 시간에 필요한 일정, 준비물, 격려의 메시지를 1분 만에 작성하고 보관.
  - 카카오톡, 밴드 등 학급 SNS에 올리기 적합한 정제된 규격의 카드뉴스형 PNG 이미지 즉시 생성.
  - 과거에 안내했던 공지사항을 날짜·테마·본문 키워드로 즉시 검색 및 재활용.

### 2.2 대상 사용자 페르소나
- **메인 사용자 (교사)**: 성일정보고 도제 3-12반 담임교사 (이상호 선생님)
  - 아침 조회 전 빠르고 편리하게 알림장을 작성하고 수정해야 함.
  - 텍스트 공지뿐 아니라 학생들의 이목을 끄는 카드뉴스 형태의 시각자료를 메신저로 전송하고자 함.
  - 복잡한 서버 운영이나 월 과금 없이 안전하게 데이터를 관리하고 싶어 함.
- **최종 소비자 (학생/학부모)**: 도제 3-12반 학급 학생 및 학부모
  - 정돈된 형태의 이미지로 오늘의 핵심 일정과 과제, 준비물을 직관적으로 확인.

### 2.3 사용자 시나리오 (User Journey)
```
[접속 및 인증]
  └─ 암호화된 마스터 비밀번호 입력 (30분 세션 토큰 획득)
       │
[대시보드 진입]
  ├─ 통계 요약 확인 (전체 알림 수, 이번 달 등록 수, 오늘 날짜)
  │
  ├─ [시나리오 A: 새 알림장 작성]
  │    1. 캘린더 위젯에서 날짜 선택 (기본값: 오늘)
  │    2. 10가지 감성 테마 중 오늘에 맞는 분위기 선택
  │    3. 본문 작성 ([준비물] 등 대괄호로 강조 배지 표시)
  │    4. 우측 '실시간 공유 미리보기'로 카드 형태 확인
  │    5. 등록 완료
  │
  ├─ [시나리오 B: 알림 공유 및 다운로드]
  │    1. '알림 보관함' 탭 이동 (또는 ⌘K 단축키)
  │    2. 카드 하단 '이미지로 저장(↓)' 클릭
  │    3. 모바일: 카카오톡 등 네이티브 공유창 호출 / PC: 고해상도 PNG 즉시 다운로드
  │
  └─ [시나리오 C: 과거 알림 검색 및 수정/삭제]
       1. 통합 검색창에서 키워드 검색
       2. 카드 내 '편집(✎)' 클릭 시 작성 폼으로 자동 로드되어 수정
       3. 카드 내 '삭제(×)' 클릭 시 안전 확인 후 영구 삭제
```

- **URL**: `https://script.google.com/macros/s/{DEPLOYMENT_ID}/exec`


  - `checkPassword`: 패스워드 인증 및 세션 토큰(`token`, 30분 유효) 발급

  - `update`: 기존 알림 수정 (ID 매칭 행 수정)
  - `delete`: 알림 영구 삭제 (ID 매칭 행 삭제)

## 4. 보안 및 동시성 제어 설계

1. **비밀번호 관리 (Fail-Closed Architecture)**:
   - 비밀번호 원문은 서버나 데이터베이스 어디에도 저장되지 않습니다.
   - `UUID` 기반 고유 솔트(Salt)와 조합하여 `SHA-256` 해싱 후 `PropertiesService`에 저장됩니다.
   - 비밀번호 비교 시 타이밍 공격(Timing Attack)을 차단하기 위해 XOR 연산 기반의 상수 시간 비교 함수(`safeEqual_`)를 사용합니다.
2. **세션 및 레이트 리밋 (Rate Limiting)**:
   - 5회 연속 잘못된 비밀번호 입력 시 5분(`300초`) 동안 로그인이 강제 차단됩니다.
   - 발급된 세션 토큰은 64자 이상의 고엔트로피 문자열로 생성되며, 활동 시 30분씩 유효 시간이 연장됩니다.
3. **인젝션 공격 방지 (Formula & XSS Injection)**:
   - 본문 첫 글자가 `=`로 시작하는 경우 `'` 기호를 접두어로 삽입하여 스프레드시트 내부 수식 실행을 방지합니다(`asSheetText_`).
   - 클라이언트 렌더링 시 `innerHTML` 대신 `textContent` 및 DOM 조작 메서드를 사용하여 XSS를 원천 차단합니다.
4. **동시성 잠금 (Concurrency Lock)**:
   - 생성, 수정, 삭제 작업 시 `LockService.getScriptLock()`을 최대 10초간 획득하여 동시 요청에 의한 데이터 덮어쓰기 및 레이스 컨디션을 방지합니다.

## 5. 설치 및 배포 가이드

### 5.1 Google Apps Script (GAS) 백엔드 구축
1. [Google Drive](https://drive.google.com/)에서 새 스프레드시트를 생성합니다 (예: `도제 3-12 알림장 DB`).
2. 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
3. 기본 생성된 `Code.gs`의 내용을 이 프로젝트의 [`code.gs`](file:///g:/Project%20mooksys.github.io/school_project26/project_03_greeting/code.gs) 내용으로 전부 덮어쓰고 저장(`Ctrl + S`)합니다.

### 5.2 관리자 접속 비밀번호 설정
1. 스프레드시트 화면으로 돌아와 페이지를 새로고침(`F5`)합니다.
2. 상단 도구 메뉴에 새로 생긴 **알림장 관리 → 접속 비밀번호 설정/변경**을 클릭합니다.
3. 사용할 10~128자 비밀번호를 2회 입력합니다 (`1234` 등 단순 비밀번호는 거부됩니다).
4. 설정 완료 알림창이 뜨면 백엔드 인증 준비가 완료됩니다.

### 5.3 GAS 웹 앱 배포
1. Apps Script 편집기 우측 상단의 **배포 → 새 배포**를 클릭합니다.
2. 유형 선택에서 **웹 앱(Web App)**을 선택합니다.
   - **설명**: `Morning Note API v1.0`
   - **다음 사용자로 실행**: `나 (My account)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** *(웹 클라이언트에서 API 통신을 위해 필수)*
3. **배포** 버튼을 누르고 생성된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 5.4 프런트엔드 연동 및 배포
1. [`school_project_03_gas_url.json`](file:///g:/Project%20mooksys.github.io/school_project26/project_03_greeting/school_project_03_gas_url.json) 파일을 열어 복사한 URL을 붙여넣습니다:
   ```json
   {
     "webAppUrl": "https://script.google.com/macros/s/AKfycbx.../exec"
   }
   ```
2. 다음 파일들을 GitHub Pages, Cloudflare Pages, Netlify 또는 정적 웹 호스팅 서버에 업로드합니다:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `school_project_03_gas_url.json`
   - `og.png`
3. 브라우저에서 배포된 웹사이트 주소(`index.html`)로 접속하여 로그인합니다.

> [!TIP]
> **로컬 개발 시 주의점**  
> `index.html`을 파일 탐색기에서 더블클릭(`file://`)으로 열면 브라우저의 보안 정책(CORS)으로 인해 로컬 JSON 설정 파일을 읽지 못할 수 있습니다. 로컬 테스트 시에는 VS Code의 **Live Server** 익스텐션이나 `npx serve` 등의 로컬 HTTP 서버를 통해 실행하는 것을 권장합니다.

## 6. 사용 가이드 및 팁

### 1) 대괄호 `[...]` 배지 강조 문법
전달사항 본문 작성 시 강조하고 싶은 핵심 키워드를 대괄호로 묶으면 자동으로 전용 배지 스타일로 렌더링됩니다.
- 예시 입력:
  ```text
  [오늘의 준비물] 실습 교재 및 개별 필기도구
  [제출 기한] 오후 4시까지 반장에게 제출해 주세요.
  오늘도 서로를 응원하며 즐거운 하루를 만들어 갑시다!
  ```
- 변환 효과: `[오늘의 준비물]`, `[제출 기한]` 단어가 세련된 라운드 배지 박스로 전환되어 가독성이 극대화됩니다 (Canvas 이미지에도 동일 적용).

### 2) 효율적인 검색 단축키
- `⌘ + K` (Mac) 또는 `Ctrl + K` (Windows): 보관함 탭으로 즉시 전환되며 검색창에 포커스됩니다.
- `ESC`: 검색창 입력 내용 즉시 초기화.

### 3) 이미지 저장 및 학급 공유
- 알림 카드 우측 하단의 **다운로드 아이콘(↓)**을 누르면 자동으로 850px 태블릿 규격의 선명한 그래픽 카드가 생성됩니다.
- 스마트폰(아이폰/갤럭시) 브라우저에서 접속 시 즉시 카카오톡, 라인, 문자 등으로 전송할 수 있는 시스템 공유 시트가 실행됩니다.
